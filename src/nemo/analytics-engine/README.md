# Analytics Engine Service

Go service that provides FlightSQL proxy functionality with connection pooling, query caching, and rate limiting. Also handles pod orchestration for session-based workflows (deprecated).

## Responsibilities

- **FlightSQL Proxy** (NEW): Connection-based API with connection pooling, query caching, and rate limiting
- **Session Management** (DEPRECATED): Pod orchestration (GizmoSQL deployment with init container)
- Query execution via Arrow Flight SQL
- Status reporting (polling endpoint)

## API Endpoints

### FlightSQL Proxy API (NEW - Recommended)

Connection-based endpoints that directly connect to FlightSQL servers:

- `POST /api/flightsql/connect` - Initialize connection pool
- `POST /api/flightsql/disconnect` - Close connection pool
- `POST /api/flightsql/query` - Execute SQL query (returns Arrow IPC or JSON)
- `POST /api/flightsql/upload` - Upload file and load into database
- `POST /api/flightsql/load-arrow` - Load Arrow IPC data into database
- `POST /api/flightsql/load-objects` - Load JavaScript objects into database

**Features:**
- Connection pooling with health checks (min: 2, max: 10 connections per config)
- Query result caching for metadata queries (TTL: 5 minutes)
- Rate limiting (60 req/min for queries, 10 req/min for uploads)
- Returns Arrow IPC format by default (JSON with `Accept: application/json` header)
- Automatic cache invalidation on data modifications

**Monitoring:**
- `GET /health` - Health check with connection pool and cache statistics
- `GET /metrics` - Detailed metrics including performance, cache, and connection stats

See [Migration Guide](../../../docs/analytics/analytics-engine-migration-guide.md) for details.

### Session-based API (DEPRECATED - Will be removed July 1, 2025)

**⚠️ These endpoints are deprecated and will be removed in July 2025. Migrate to the FlightSQL Proxy API.**

#### Internal APIs (called by analytics-service)

- `POST /api/v1/internal/sessions` - Create session (initialize pod) ⚠️ DEPRECATED
- `GET /api/v1/internal/sessions/:sessionId/status` - Get session status ⚠️ DEPRECATED
- `DELETE /api/v1/internal/sessions/:sessionId` - Delete session (stop pod) ⚠️ DEPRECATED

#### Public APIs (called by GUI)

- `POST /api/v1/sessions/:sessionId/query` - Execute SQL query ⚠️ DEPRECATED
- `GET /api/v1/sessions/:sessionId/schema/:tableName` - Get table schema ⚠️ DEPRECATED

All deprecated endpoints return these headers:
- `Deprecation: true`
- `Sunset: 2025-07-01`
- `Link: </api/flightsql/query>; rel="successor-version"`

## Environment Variables

- `PORT` - Server port (default: 5000)
- `K8S_NAMESPACE` - Kubernetes namespace (default: default)
- `DEPLOYMENT_ID` - Deployment ID for session polling (default: namespace)
- `ANALYTICS_SERVICE_URL` - Analytics service URL (default: http://analytics-service.nemo.svc.cluster.local:4000)
- `GIZMOSQL_USERNAME` - GizmoSQL username (default: gizmosql_user)
- `GIZMOSQL_PASSWORD` - GizmoSQL password (default: auto-generated per session)

## Building

### First Time Setup

```bash
cd src/nemo/analytics-engine
go mod download
go mod tidy  # This will generate go.sum automatically
```

### Build

```bash
# From project root
make build-nemo

# Or manually
cd src/nemo/analytics-engine
go build -o analytics-engine .
```

### Docker Build

```bash
# From project root
make docker-build-service SERVICE=analytics-engine

# Or manually
docker build -f src/nemo/analytics-engine/Dockerfile -t analytics-engine:latest .
```

## Development

### Run Locally

```bash
cd src/nemo/analytics-engine
go run main.go
```

Note: Running locally requires Kubernetes access. The service uses in-cluster config, so it's designed to run inside Kubernetes.

## Features

### Connection Pooling
- Automatic connection pooling per connection configuration
- Health checks every 60 seconds
- Idle connection cleanup after 5 minutes
- Configurable pool sizes (min: 2, max: 10)

### Query Caching
- Automatic caching of metadata queries (SHOW TABLES, DESCRIBE, INFORMATION_SCHEMA)
- Cache TTL: 5 minutes (configurable)
- Automatic cache invalidation on data modifications
- LRU eviction when cache is full

### Rate Limiting
- Query endpoints: 60 requests/minute
- Upload endpoints: 10 requests/minute
- Per-IP rate limiting
- Returns 429 status when limit exceeded

### Metrics and Monitoring
- Connection pool statistics
- Cache statistics (size, hit rate)
- Query statistics (total, errors, error rate)
- Performance metrics (avg, p95, p99 response times)
- Request counts by endpoint

## Notes

- `go.sum` is automatically generated by `go mod tidy` - do not create it manually
- The service requires Kubernetes RBAC permissions for Deployments, Services, and Pods
- Designed to run in-cluster (uses in-cluster Kubernetes config)
- Uses Kubernetes client-go v0.28.4 (consistent with TypeScript services using @kubernetes/client-node v1.4.0 for K8s 1.28)
